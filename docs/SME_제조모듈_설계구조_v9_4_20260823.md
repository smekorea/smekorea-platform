## ★ v9.2 작업 일지 (2026-06-18) — mfg_stock.html 전면개선

### ① 입출고 등록 탭 — 레이아웃 재구성 + 최근저장결과 통합

**배경**: 우측 등록폼(①~④ 섹션)이 세로로 길어 한 화면에 다 보이지 않는 문제 + BOX단위(릴당 대량) 입고 시 자동저장된 수량을 사후 수정할 방법이 없는 문제.

**레이아웃 변경**
- 좌측 사이드바 폭 확대: `400px → 480px` (`grid-template-columns`)
- 우측 영역 패딩 축소(`16px→14px`)로 입력칸 폭 최적화
- ① 릴 바코드 스캔: SCAN1~4 박스를 2×2(2줄) → **1×4 한 줄** 배치로 압축
- ② LG품번 섹션: 입력창+결과창 세로 2단 → **③메이커품번·LOT처럼 가로 2단** 배치로 통일

**"스캔 부품 정보" + "최근 저장 결과" 통합 (핵심 변경)**
- 기존: 스캔 중 임시정보 카드(좌측, 3초 후 사라짐)와 저장결과 카드(우측 하단, 별도 박스)가 분리되어 있었음
- 변경: **하나의 박스**(`mv_scanInfoList` + `mv_lastCard`)로 통합, 상태에 따라 상호배타적으로 전환
  - 새 스캔이 **BOM 매칭 완료**되는 시점 → `hideLastMoveCard()` 호출 → 직전 저장카드 숨김 + 스캔정보 노출
  - **자동저장(또는 수동저장) 성공** 시점 → `showLastMoveCard()` 호출 → 스캔정보 숨김 + 저장카드(아이보리 배경, 수정가능) 노출
  - 즉, 저장 완료 후 다음 스캔이 매칭되기 전까지는 직전 저장 결과가 화면에 계속 유지됨

**저장 결과 수정 기능 (BOX단위 입고 대응)**
- 카드 우측 "✏️ 수정" 버튼 클릭 → 수량 입력창 활성화 (시간 제한 없음, 카드가 떠 있는 동안 항상 가능)
- "완료" 클릭 시:
  1. **새 행을 추가하지 않고**, 방금 저장된 `mfg_stock_move` 레코드 자체를 `id` 기준으로 `UPDATE` (수량만 보정)
  2. `mfg_stock_current` 재고는 **차이값(diff)만큼만 보정** — 예: 5,000 → 50,000 수정 시 diff=+45,000만 추가 반영하여 최종 재고가 정확히 50,000이 되도록 처리
- `insert().select()`로 저장 시 반환된 행 객체(`_lastMove`, id 포함)를 그대로 보관하여 수정 시 정확히 그 레코드를 타겟팅

**카드 색상 규칙**
- 스캔 중(매칭 카드): 반투명 흰색 (`.scan-card`, 기존 유지)
- 저장 완료(수정가능 카드): **아이보리** (`.scan-card.last-saved`, `background:#fdf8ec; border:#e8dcc0`) — 어두운 사이드바 배경과 자연스럽게 대비, "스캔중/저장완료" 상태를 색감으로도 구분

### ② 재고 현황 탭 — 전면 개편

**검색 기능**
- 기존 통합검색 1칸(`st_kw`) → **품번 검색칸 / LOT 검색칸 2개로 분리** (`st_kw_pn` / `st_kw_lot`)
- "🔍 검색" 버튼 추가 — 클릭 시 DB 재조회(`loadStock()`)까지 함께 수행 (기존 "새로고침" 버튼 삭제, 검색이 그 역할을 겸함)

**품번기준 합산 보기 (신규)**
- "📊 품번기준 보기" 토글 버튼 추가 (위치는 검색 버튼 옆)
- ON 시: 현재 위치 필터 기준으로 **LOT 무시하고 품번별 합산** 표시, 행 클릭 시 LOT별 상세 펼침(▶/▼)
- OFF 시: 기존처럼 LOT별 개별 행 표시

**정렬 — 헤더 클릭 정렬 표준 적용**
- 기본 정렬: **리딩시각(`updated_at`) 내림차순** (최신이 상단)
- 모든 헤더(위치/LG품번/Maker/LOT/수량/리딩시각) 클릭 시 오름차순/내림차순 토글, `↑↓` 아이콘 표시
- 표준 유틸 `_setSortIcons()` / `_cmp()` 적용 (SME_컨텍스트 표준과 동일 패턴)

**"재고없음" 표시 제거 + 원인**
- **원인**: 출고(불출 등) 시 해당 위치에 기존 재고 레코드가 없으면 `updateStockCurrent()`가 자동으로 0짜리 행을 생성. 또한 같은 자재라도 스캔 횟수가 달라 LOT 문자열이 달라지면(`join(' / ')` 결과가 매번 다름) 별도 행으로 분리되어 재고없음처럼 보이는 사례도 있었음
- **결정**: LOT은 스캔값 그대로 별개로 저장(통일 로직 도입 안 함, 있는 그대로가 LOT)
- **처리**: 재고 0인 행은 목록/엑셀/KPI 집계에서 **항상 숨김** — "재고없음" 배지 자체를 화면에서 제거

**리딩시각 표시 수정**
- 기존: `updated_at.substring(5,16)` 문자열 단순 절단 → `06-09T04:16` 형태로 깨져 보임
- 변경: 컬럼명 **"최근 업데이트" → "리딩시각"**, `new Date(v)`로 파싱 후 브라우저가 로컬(KST) 자동 변환 → `fmtKst()` 함수로 `YYYY-MM-DD HH:mm:ss` 포맷 적용

**표준 4종 적용**
- 리사이저블 컬럼: `initColResize('st_table','mfg_stock_col_w')`
- 헤더 클릭 정렬, 세로 테두리(`border-right:1px solid #e8edf5`), 텍스트 검정(`color:#111827`)

**헤더 틀고정(sticky)**
- `.tw` 컨테이너에 `max-height:560px; overflow-y:auto` 적용
- `#st_table thead th{position:sticky;top:0;z-index:5}` — 스크롤 시에도 헤더 고정

**버튼/UI 정리**
- "📥 엑셀" → **"📥 엑셀 다운로드"**로 텍스트 변경
- "🔄 새로고침" 버튼 삭제 (검색 버튼이 역할 통합)

### 생산실행 핵심 흐름
```
라인+날짜 선택 → 작업목록 표시
→ [생산 시작] → 현품표 리딩 팝업 (바코드스캔 or 직접입력)
→ WO번호 자동생성 (WO-YYYYMMDD-L1-001 형식)
→ sessionStorage에 WO정보 저장
→ mfg_lot.html 피더체크 탭으로 이동
→ 피더체크 완료 후 복귀 → 생산중 상태 자동전환
→ [완료 등록] → 양품수량 입력 → 잔여처리(이월/DROP)
→ 가동율/실장점수/매출금액 자동계산 저장
```

### 실가동시간 계산
```
정상근무: 08:20~17:30 → 휴식 70분 차감 → 실가동 8.0시간
잔업:     18:00~23:00 → 실가동 2.5시간
정상+잔업: 실가동 최대 10.5시간
17:30~18:00: 비가동 인터벌 (계산 제외)
실제 완료시간 기준 자동계산
```

### 가동율 계산
```
SMT 라인:
  실장점수 = SUM(mfg_bom_model.qty WHERE model_code=모델) × 양품수량
  가동율(%) = 실장점수 / (capa_per_hour × 실가동시간) × 100

조립라인:
  가동율(%) = 양품수량 / (capa_per_hour × 실가동시간) × 100
```

### WO번호 체계
```
WO-YYYYMMDD-라인코드-순번
라인코드: 1라인=L1, 2라인=L2, 3라인=L3, 조립라인=LA
예) WO-20260513-L1-001
```

## ★ 핵심 주의사항 및 교훈

| 항목 | 내용 |
|---|---|
| **mfg_stock_move 사후수정** | id 기준 UPDATE로 처리, 새 행 추가 금지. `mfg_stock_current`는 diff(차이값)만 보정 |
| **재고 0 표시** | 화면(목록/엑셀/KPI)에서 항상 숨김. "재고없음" 배지 제거 (v9.2) |
| **LOT 키 정책** | 스캔값을 그대로 저장(통일 로직 없음) — 스캔횟수가 다르면 다른 LOT로 별도 취급이 정상 동작 |
| **KST 시각 표시** | `new Date(isoString)` 파싱 후 브라우저 로컬변환에 의존. 문자열 substring 절단 금지 |
| spec_maker_pn vs old_maker_pn | spec=BOM등록값, old=실제스캔/수동입력값. 절대 혼동 금지 |
| 수동입력 품번 저장 | `_rc.oldPn`/`_rc.newPn`에 저장 후 `saveReelChange`에서 fallback 처리 |
| 수동입력 NG 처리 | `showWrongPartAlert` 미존재 함수 금지 → 반드시 `showNgReasonPopup` 사용 |
| 피더목록 잠금 | `_fc.allDone=true` 시 `renderFcList()`에서 클릭 attr 제거 + "체크중" 미표시 |
| extractPn() 적용 | 바코드 전체값이 아닌 품번만 저장. `;` `!` `,` 구분자 기준 첫 파트 |
| NG 후 잠금 | `newNgLocked=true` 시 rc_new 입력 비활성화. `confirmNgReason()`에서 해제 |
| WO번호 중복 방지 | 생성 전 당일 동일 라인 WO 마지막 순번 조회 후 +1 |
| 가동율 계산 | `mfg_bom_model.qty` 합계 × 양품수량 = 실장점수. CAPA 미등록 시 null 저장 |
| 조립라인 구분 | `process_type='ASSY'`, 가동율=수량/시간 기준 (실장점수 없음) |
| 단가 이력 관리 | `mfg_model_price`는 insert (덮어쓰기 X). `effective_date` 최신값 자동 적용 |
| 중첩 백틱 금지 | 템플릿 리터럴 안에 백틱 중첩 → SyntaxError |
| 하이픈→언더바 | 바코드/모델코드 정규화: `replace(/-/g,'_').toUpperCase()` |
| ExcelJS row height | `addRow()` 직후 즉시 설정 — defaultRowHeight/views 방식 동작 안함 |
| LG품번 기준 | 배치 마스터는 LG품번만 저장, 나머지 속성은 BOM에서 조인 |
